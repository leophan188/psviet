# 03. Bài đăng hội nhóm

## Quy tắc để không bị khóa
1. Đọc luật từng nhóm; nhiều nhóm chỉ cho bán ở mục/ngày nhất định hoặc cần admin duyệt.
2. Mỗi nhóm đăng tối đa 1 bài/ngày, mỗi bài một nội dung khác nhau; không copy y nguyên.
3. Đừng đăng cùng lúc nhiều nhóm; giãn cách ít nhất 10–15 phút.
4. Ưu tiên tham gia thảo luận, giúp người hỏi trước khi bán.
5. Ghi rõ giá, tình trạng, địa chỉ. Không nói quá, không hứa hẹn sai.
6. Dùng ảnh thật; có thể kèm link website/fanpage nếu nhóm cho phép.

## Nhóm nên tìm
Tìm trên Facebook: "PS5 Việt Nam", "Mua bán PS4 PS5", "Cộng đồng PlayStation Hà Nội", "Chợ game console", "Mua bán đồ công nghệ cũ Hà Nội".
Ghi lại: tên nhóm, số thành viên, luật, ngày được đăng → file `nhom-facebook.csv` (tạo sau).

## Mẫu 1: Bán máy
```
[HN] PS5 bản đĩa – máy đẹp [95-98%] – đổi 7 ngày, bảo hành 3 tháng

📦 Bộ gồm: máy + 1 tay cầm + dây nguồn + HDMI
🔧 Đã test: ổ đĩa, nguồn, wifi, HDMI, tay cầm
💰 Giá: [..]đ
🎮 Miễn phí cài game vào ổ cứng
🚚 Ship COD toàn quốc / xem máy tại [địa chỉ HN]
Máy nguyên bản. Ảnh/video thật bên dưới 👇
Inbox hoặc Zalo [SĐT].
```

## Mẫu 2: Chia sẻ kinh nghiệm
```
Mua PS5 cũ cần kiểm tra gì? Checklist 8 điểm shop hay dùng:
1. Bật máy, vào menu, kiểm tra nhiệt độ/quạt
2. Test ổ đĩa (nếu bản đĩa) bằng 1 đĩa thật
3. Test HDMI, cổng USB, wifi/Bluetooth
4. Kiểm tra tay cầm: drift, nút, sạc
5. Xem tem/số serial, tình trạng ốc vít
6. Kiểm tra tài khoản/xóa dữ liệu về mặc định
7. Hỏi rõ bảo hành
8. Nên xem máy trực tiếp hoặc yêu cầu video quay thật
Bạn cần tư vấn thêm cứ hỏi, shop trả lời ở dưới 👇
```

## Mẫu 3: Hỏi nhu cầu
```
Bạn đang chọn PS5 bản đĩa hay Digital? Ngân sách khoảng bao nhiêu?
Comment giúp shop, shop gợi ý cấu hình phù hợp, miễn phí tư vấn.
```

## Mẫu 4: Feedback
```
Khách ở [tỉnh] vừa nhận máy qua COD 🎉
[Ảnh/ tin nhắn feedback đã được khách đồng ý]
PSVIET.COM – kiểm tra kỹ, bảo hành rõ ràng.
```

## Mẫu trả lời bình luận
- "Cho mình xin giá": "Chào bạn, shop đã inbox giá chi tiết nhé!"
- "Máy còn không?": "Máy còn bạn nhé, bạn nhắn shop để giữ máy."
- "Có lừa đảo không?": "Shop ở [địa chỉ], bạn đến xem trực tiếp, hoặc nhận COD kiểm tra rồi thanh toán ạ."
